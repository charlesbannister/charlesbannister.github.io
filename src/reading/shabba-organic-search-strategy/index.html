Where Shabba should compete in Google Search

Recommendation for Charles · 19 November 2026

Start with the advertiser who has a messy search terms report. Shabba can help them find searches they might want to exclude, understand why a rule flagged them and choose how much to automate. Make that job easy to find and try. Then use the free scripts directory to introduce the other jobs Shabba does well.

Why start here?

In the 90 days ending 15 November, the marketing site earned 28 Google clicks from 3,344 impressions. The previous 90 days brought 66 clicks from 3,978 impressions. The same dates a year earlier brought 79 clicks from 3,207 impressions. Visibility is close to last year’s level, but fewer appearances are bringing people to the site.

The clearest product opportunity is the free negative keyword script. Its Sheets page fell from 18 clicks to 3 and from 938 impressions to 189 between the two recent periods. Its average position slipped from 11.4 to 16.3. The cause is still open. All 50 sitemap pages passed the basic crawl checks, so I’d put the first effort into the page an advertiser actually lands on.

Three searches worth earning

1. “Google Ads negative keyword script”

Make the existing Sheets URL the main entry point. Someone searching for a script should be able to copy the Sheet and get the code immediately. Give the visitor who is still deciding a practical promise: preview which search terms your rules would flag before you exclude them.

Put the interactive example near the top. Let a visitor edit a search term, switch between custom words and example ad group keywords, and see why the same search can be kept or flagged. Label the keyword-based example as a hybrid feature. A small working example gives an advertiser more reason to trust the tool than a claim about how much money it might save.

Group the two self-run scripts together. The Sheets version puts the settings in the spreadsheet. The actively maintained hybrid offers more rule options in a web dashboard and optional AI analysis with the advertiser’s own API key. Give the hosted Search term tamer its own section for visitors who want to connect Google Ads and approve selected negatives without installing a script. Keep the installation details and existing links accessible. Sheets script · Hybrid dashboard · Search term tamer

2. “Free PPC scripts” and “free Google Ads scripts”

The existing directory went from 40 to 169 impressions for “free PPC scripts”, and average position improved from 28.0 to 24.6. Help that visitor choose a script by the job they have today. For each featured script, show what it checks, one example result, and whether it can change an account. Start with negative keywords and send visitors directly to the script or its installation guide. Free scripts directory

3. “Keyword wrapper” and “Google Ads keyword wrapper”

“Keyword wrapper” rose from 108 to 168 impressions. “Keyword wrapper tool” earned another 66 in the latest period. Neither query recorded a click. My hypothesis is that these visitors want to paste a list, select phrase or exact match, and copy the result immediately. Check target-market demand in Keyword Planner before building an in-page wrapper. Keep the Chrome extension as the option for repeat users. Existing wrapper page

What to do first, and how to judge it

  1. Approve the negative keyword page and publish it first. Keep its established address. Link to it from the homepage walkthrough, the scripts directory and the earlier announcement. Give the homepage a plain description of the Google Ads jobs Shabba can do.
  2. Improve the directory next. Use real examples from the scripts. Defer a broader content programme until these existing pages show which jobs attract visitors.
  3. Measure useful visits. Record release dates. After 28 complete days, compare impressions, clicks and average position for the target queries and pages against the preceding 28 days. Also track script downloads or clicks to the template, hybrid dashboard visits and hosted-app signups. Recheck at 90 days because click counts are small.

Decision requested: give the negative keyword landing page and scripts directory the next two marketing slots. Keep the wrapper as a demand check. No search-volume estimate or ranking uplift is assumed.
