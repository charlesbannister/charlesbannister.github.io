Where I can help

Website design and build

Website questions

Can you work with the site I already have?

Yes. We can start with a page, a form or a checkout flow. I’ll bring up a rebuild if it solves a problem we can’t address well on the current site.

Will you write the copy and set up the tracking?

I can do both. I’ll need your input on the offer, proof and customer questions. We’ll agree which actions to measure before I build the page.

Can we run an A/B test with a small amount of traffic?

We can, but it may take too long to get a clear answer. With lower traffic I usually start by fixing obvious problems and use customer feedback and directional data to choose what to improve next.

Can you work with my designer or developer?

Yes. I’ve been programming for over 15 years, most of that time professionally, including building software for GoDaddy. I can handle the build myself and I’m happy to work with your existing designer or developer.
